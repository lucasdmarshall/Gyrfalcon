# gyrfalcon

Sealed-segment hybrid retrieval: an owned BM25 index and a graph-free dense cascade, fused.

This crate is the engine. `gyrfalcon-ingest` turns PDF, HTML, and text files into text. The `gyr` binary is the `gyr-cli` crate. Python installs the `gyrfalcon-rag` distribution and imports `gyrfalcon`.

Repository: <https://github.com/lucasdmarshall/gyrfalcon>
