# gyr-cli

The `gyr` command: index a directory, query it, serve the HTTP API, compact, and run the benchmarks.

It is a thin front end over the `gyrfalcon` and `gyrfalcon-ingest` crates. Python users install `gyrfalcon-rag` instead of this crate.

Repository: <https://github.com/lucasdmarshall/gyrfalcon>
